# Shopify Docs

This folder is the living record for the Shopify side of Molecule OS (scope: `apps/shopify-app/**`, `packages/shopify/**`, Shopify-facing scripts — see [`docs/TASKS/SHOPIFY.md`](../../../docs/TASKS/SHOPIFY.md)).

| File | Purpose | Update cadence |
| --- | --- | --- |
| [`STATUS.md`](STATUS.md) | Current implementation state vs. the owner task's definition of done | Every session that touches Shopify code |
| [`CHANGELOG.md`](CHANGELOG.md) | Dated, append-only log of what changed and why | Every commit that touches Shopify scope |
| [`COMPETITIVE_STRATEGY.md`](COMPETITIVE_STRATEGY.md) | Research on the Hack the North Shopify track and concrete ideas to make this submission win | As new research lands or the plan changes |

Read [`docs/ARCHITECTURE.md`](../../../docs/ARCHITECTURE.md) and [`docs/CONTRACTS.md`](../../../docs/CONTRACTS.md) first — this folder assumes that context and does not repeat it.
