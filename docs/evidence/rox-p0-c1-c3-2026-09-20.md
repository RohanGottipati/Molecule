# ROX P0 C1/C3 evidence — 2026-09-20

Scope: immutable resolution evidence and a same-population comparison of the
agent extraction pipeline with the deterministic regex baseline. This is a
synthetic regression benchmark, not a real-document accuracy claim.

## Frozen resolution evidence

Migration `022_rox_resolution_snapshots.sql` adds an insert-only decision row
for each `(run_id, merchant_id, field)`. The row contains the status, winner,
normalized value/unit, complete scored contenders, claim IDs, explanation, and
resolution time. `score.mjs` reads those rows inside the same repeatable-read
transaction as the remaining evaluation inputs and includes `resolve.mjs` in
the report's source hashes.

`rox-evaluation-v3` never reads `canonical_resolutions`. If a report has no
run-specific snapshot, outlier containment is `null` with an explicit
limitation. Replaying a frozen report produces the same evaluation result; the
test suite also proves that changing only the frozen winner changes the outlier
verdict.
